# 骑行路线导出 GPX

把路线编号、地图分享链接，或一句路线描述，变成可导入码表和骑行软件的 GPX。

适用于支持 Skill 和脚本执行的 Agent 产品，不局限于 Codex。

## 支持哪些功能

| 功能 | 使用场景 | 使用示例 |
|---|---|---|
| iGPSPORT 路线导出 | 已有 iGPSPORT 路书，想导入码表或其他骑行软件 | 导出 iGPSPORT 路线编号 18154 的 GPX |
| 高德分享转 GPX | 已在高德规划好骑行路线，想转成 GPX | 把这个高德骑行路线分享链接转成 GPX |
| 百度分享转 GPX | 已在百度规划好骑行路线，想转成 GPX | 把这个百度骑行路线分享链接转成 GPX |
| 自然语言规划 | 只有起终点和骑行偏好，希望 AI 帮忙规划路线 | 使用高德，从杭州武林广场到钱塘江城市阳台，尽量走绿道 |

高德和百度分享会保留起点、途经点和终点的顺序，使用对应地图的骑行规划重新制作路线，可能与 App 中的原方案不同。部分分享格式暂不支持，无法识别时会提示补充地点。

## 自然语言规划怎么用

适合还没有现成路线，只知道从哪里出发、骑到哪里，或希望“尽量走绿道”“沿江骑行”“途经某个地点”的场景。

告诉 Agent 起点、终点、途经点和路线要求即可。例如：
- “使用高德，从杭州武林广场到钱塘江城市阳台，尽量走绿道。”
- “使用百度，从成都天府广场到青龙湖湿地公园，途经东安湖公园，先让我看看路线。”
- “帮我规划一条从上海世纪公园到前滩休闲公园的骑行路线，尽量沿江走，确认后导出 GPX。”

**选择地图 → 规划路线 → 展示路线图 → 你确认 → 导出 GPX**

没有指定高德或百度时，会先让你选择。路线可以调整，确认后按图中同一条轨迹导出。


## 安装

下载本仓库，放入你使用的 Agent 产品的 Skill 目录，或直接让 AI 安装此 Skill。

运行环境需要 **Python 3.10+、curl 和网络访问权限**。路线图可通过浏览器或 Agent 的 HTML 预览查看。

## 首次使用需要配置什么

- **iGPSPORT**：无需地图密钥。
- **高德**：需要自己的 Web 服务 Key。
- **百度**：需要自己的服务端 AK。

首次使用时，Agent 会引导你申请并安全配置。**成功保存后，同一用户、同一运行环境下自动读取，无需重复提供。**

密钥不写入 Skill 或 GitHub 仓库。换设备或运行环境时，需要重新配置。

详细步骤见[使用说明](https://github.com/PIXELLL7-UX/cycling-route-gpx/blob/main/references/usage.md)。
