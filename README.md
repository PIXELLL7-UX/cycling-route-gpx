# 骑行路线导出 GPX

一个通用的 Agent Skill，支持将 iGPSPORT 和高德骑行路线导出为 GPX，方便导入码表或骑行软件。

## 支持功能

- **iGPSPORT 路书导出**：提供路书编号，即可下载 GPX。
- **高德路线转 GPX**：提供自行车路线分享链接，保留起终点和途经顺序，通过高德官方骑行规划生成 GPX。
- **规划新的骑行路线**：提供起点、途经点和终点，生成骑行路线并导出。

> 高德分享路线会重新规划，结果可能与 App 中的原方案有所不同。

## 安装与使用

下载本仓库，将整个文件夹导入你使用的 Agent 产品的 Skill 目录，或直接让 AI 安装此 Skill，然后直接提出请求，例如：

- “导出 iGPSPORT 路书 3074600 的 GPX。”
- “把这个高德骑行分享链接转成 GPX。”
- “从世纪公园骑到东方明珠，途经上海科技馆，导出 GPX。”

## 运行要求

不局限于 Codex，适用于支持 Skill 或脚本调用的 Agent 产品。运行环境需要 **Python 3.10+、curl 和网络访问权限**。

高德功能需要申请 **高德 Web 服务 Key**，可参考[官方申请指引](https://lbs.amap.com/api/webservice/create-project-and-key)。

导出后会提供 **GPX 文件、路线名称、里程和轨迹点数**。
